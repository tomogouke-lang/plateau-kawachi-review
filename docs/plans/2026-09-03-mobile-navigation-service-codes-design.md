# 河内店LP 上部導線・サービスコード・携帯改行の修正設計

## 目的

既存の構成と内容を保ったまま、一般向けLPからケアマネジャー向けLPへ移動しやすくし、ケアマネジャー向けLPに実務で確認するサービスコードを掲載する。携帯では、見出しの末尾1〜2文字だけが次の行に残る不自然な改行を防ぐ。

## 変更範囲

- 一般向けLPの上部メニューに「ケアマネジャー向け」を追加する。
- 一般向けLPの最初の案内部分のボタンを、次の順番にする。
  1. 河内店の特色を見る
  2. 空き状況・料金を見る
  3. ケアマネさん向け
- 下部の既存リンクは残す。
- ケアマネジャー向けLPに事業所番号とサービスコード欄を追加する。
- ケアマネジャー向けLPの見出しだけ、意味のまとまりを保つ携帯向け改行にする。

## 根拠

- 上部導線の配置は北安江2号店を参考にする。ただし一般向けの案内を主役にし、ケアマネジャー向けボタンは3番目に置く。
- 事業所番号は厚生労働省の介護サービス情報公表システムで確認する。
- 地域密着型通所介護は令和8年6月1日版の地域密着型サービスコード表、介護予防型通所サービスは白山市の令和8年6月対応版コード表で確認する。
- 現在の料金計算で使用中の通常算定項目のみを掲載し、算定していない加算を増やさない。

## 変更しないもの

- パンフレットとQRコード
- LP本文の順序、写真、料金計算、空き状況連動
- 河内店以外の既存LP（携帯表示の点検と報告だけ行う）
- 公開状態

## 確認

- 320px、375px、390px、430px、768px、1440pxで表示を確認する。
- 一般向けLPのボタン順、リンク先、下部リンクが残っていることを確認する。
- ケアマネジャー向けLPのコードと単位数を公式表と照合する。
- 公開・pushは画面確認後に別途承認を得る。
